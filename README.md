**INVENTORY MANAGEMENT**

**Tech Stack: Java, Spring Boot, Data JPA, MySQL DB, Spring Web, HTML, Bootstrap CSS**

Inventory Management system supporting individuals/companies in maintaining current inventory. Application supports individual products with basic product information as well as bundles to group products and sell as a set, if necessary. Users can modify all inventory items, but the system supports input validation to verify that the components are realistic.
